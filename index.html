📖 Glossaire pour les non-initiés (exemples tirés de vos fichiers)
  • Dépôt (NE1) : le site physique. Tous les fichiers sont filtrés sur NE1.
  • ZI — Zone d'Intervention : périmètre organisationnel, « qui intervient où ». Ex. ZIHUB = « Zone Intervention HUB ».
  • ZE — Zone d'Évolution : sous-zone d'une ZI, « où ça circule ». Ex. ZEHUB = « Zone Evolution HUB ».
  • ZG — Zone Géographique : plus petite zone de localisation du stock. Ex. ZGMAG3 = « LI-MAG3 ».
  • Groupe ZG (GZG…) : paquet de ZG utilisé comme point de départ ou d'arrivée des flux. Ex. GZGHUB = « Groupe ZG HUB ».
  • Tampon : zone d'attente traversée entre un groupe de départ et un groupe d'arrivée. Ex. HUBT/S = « HUB Tampon Sortie ».
  • Emplacement (F5) : adresse physique = Allée + Face + Colonne + Niveau + Emplacement. Ex. M2_LC006N4E1.
  • Séquence (F4) : ordre de priorité du tampon dans un flux.
  • Matériel (F6) : engin du parc (chariot, transgerbeur, cariste…) avec son type de matériel, sa ZI d'intervention et son emplacement parc (allée MAT, ex. MAT·117).
  • Type de matériel (F7) : catégorie Réflex : NE2 = « CHARIOT 3ème CAT.CMU 3T », NEA = « Matériel logistique », PXQ = « Transpelette elec Cat1 1,8T »… Certains sont désactivés (ex. NBT, NEB).
  • Type de support (F8) : contenant transportable : PAL = « Palette Europe sans rehausse », NK3 = « Kardex Boite Type 3 »… Le fichier F8 liste, pour chaque type de matériel, les supports qu'il peut transporter.
  • POSITION_X / POSITION_Y (F5) : coordonnées utilisées pour dessiner la carte du magasin.
Règles de jointure appliquées
  • Filtre dépôt : seules les lignes Dépôt = NE1 sont conservées (fichiers sans colonne dépôt : toutes lignes gardées) ; les autres dans « Exclus (≠NE1) ».
  • F1 : Dépôt + ZI + Groupe ZG départ → ZG de départ (la ZE n'est pas une clé).
  • F2 : grain = Dépôt + ZI + ZE flux + Groupe départ + Groupe arrivée + ZG arrivée.
  • F3 : Dépôt + ZG → une ou plusieurs ZE.
  • F4 (tampon) : Dépôt + ZI + ZE + Groupe départ + Groupe arrivée, sinon repli Dépôt + Groupe départ + Groupe arrivée.
  • F5 (emplacements) : pont = colonne Zone géo (code ZG) ; nom = concaténation Allée+Face+Colonne+Niveau+Emplacement.
  • F6 (matériel) : ponts = type_materiel → F7/F8 et zone_intervention → ZI (F1/F3) ; emplacement parc = allée+face+colonne (valeur « . » ignorée).
  • F7 (types) : clé = code ; drapeau desactivé affiché en alerte.
  • F8 (type↔support) : grain = type_materiel + type_support ; index inverse support → types construit pour la recherche « qui peut transporter ce support ? ».
  • Chemins (🧭) : emplacement → ZG (F5) → groupes (F1/F2) → flux (F2) → tampon (F4) → ZG cible → emplacements (F5).
  • Carte (🗺) : un point par emplacement F5 ayant POSITION_X et POSITION_Y renseignées, groupés par code magasin ; filtre ⏳ = emplacements tampon uniquement.
