Vos fichiers — cliquez sur « Choisir un fichier » ou glissez-déposez les classeurs ici (reconnaissance automatique par contenu). Les lignes dont le dépôt n'est pas NE1 sont écartées automatiquement.
Règles de jointure appliquées
  • Filtre dépôt : seules les lignes dont le Dépôt = NE1 sont conservées (tous fichiers). Les lignes exclues sont consultables dans l'onglet « Exclus (≠NE1) ».
  • F1 : Dépôt + ZI + Groupe ZG départ → ensemble des ZG de départ (la ZE n'est pas utilisée comme clé).
  • F2 : grain = Dépôt + ZI + ZE flux + Groupe départ + Groupe arrivée + ZG arrivée.
  • F3 : Dépôt + ZG → une ou plusieurs ZE de rattachement (non exclusif).
  • F4 (tampon) : jointure prioritaire Dépôt + ZI + ZE + Groupe départ + Groupe arrivée, sinon repli Dépôt + Groupe départ + Groupe arrivée.
  • F5 (emplacements) : pont = colonne Zone géo (code ZG) → jointure Dépôt + ZG avec F3, F1, F2.
  • Seules les lignes strictement dupliquées sont retirées. Les libellés divergents et codes atypiques sont signalés dans l'onglet Écarts.
