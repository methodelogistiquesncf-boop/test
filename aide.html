1. Principe

  • L'interface recoupe 4 référentiels Excel (zones, groupes de zones, flux, tampons) qui partagent des codes communs : Dépôt, ZI, ZE, groupes ZG, ZG.
  • Traitement 100 % local : les classeurs sont lus par votre navigateur (librairie SheetJS). Rien n'est téléversé.
  • Mémoire volatile : fermer l'onglet efface tout. À la prochaine visite, rechargez les 4 fichiers (quelques secondes).
  • Objectif : répondre instantanément à des questions du type « ce ZG dépend de quels groupes ? », « ce flux passe par quel tampon ? », « cette ZE existe-t-elle dans le référentiel ? ».

2. Démarrage

1
Ouvrez la page : URL GitHub Pages du dépôt, ou index.html en double-cliquant dessus (dans ce cas, aide.html doit être dans le même dossier).
2
Chargez les 4 classeurs avec les 4 boutons « Choisir un fichier », ou glissez-déposez-les dans la zone du haut. L'ordre n'a aucune importance : chaque fichier est reconnu par son contenu (ex. : présence des colonnes « EMPL 1…EMPL 5 » → fichier Tampon).
3
Dès qu'un fichier est lu, les KPI, filtres et tableaux se recalculent. Un bandeau orange liste les fichiers manquants et les doublons retirés.

Une connexion Internet est nécessaire au premier affichage (chargement de la librairie SheetJS). Voir la FAQ pour un fonctionnement hors-ligne.

4. Les 5 onglets

  • Flux enrichis (F2) : une ligne par flux, enrichie des ZG de départ (F1), des ZE du référentiel pour la ZG d'arrivée (F3), du chemin tampon (F4) et d'une colonne « Contrôle » (✓ ou ⚠).
  • Départ · F1 : une ligne par ZG de départ, avec ses ZE dans le référentiel F3 et l'indication « groupe utilisé dans F2 ? ».
  • Référentiel ZG · F3 : une ligne par ZG, avec son libellé (F2), ses groupes de départ (F1) et d'arrivée (F2), et « utilisé ? ».
  • Tampon · F4 : les lignes tampon telles quelles (Séquence, EMPL 1-5, Libellé, type) + « flux F2 correspondant ? ».
  • Écarts : incohérences détectées entre fichiers (section 7). Chaque pastille est cliquable pour afficher les lignes concernées.

5. Interactions — le cœur de l'outil

5.1 Cliquer sur un intitulé de colonne (🔗)

Ouvre l'Explorateur : toutes les valeurs distinctes de la colonne avec leur nombre d'occurrences, triées du plus fréquent au moins fréquent. Cliquer sur une valeur filtre toute l'interface (tableaux, KPI, autres colonnes).

5.2 Cliquer sur une valeur dans un tableau

Les valeurs affichées en pastilles sont cliquables : 1 clic = filtre ; re-cliquer la même pastille = enlever le filtre. Si une cellule contient plusieurs valeurs (ex. 15 ZG de départ), les 3 premières sont affichées plus un bouton « +N » qui ouvre l'Explorateur de la colonne.

5.3 Menus déroulants en cascade

Un menu par colonne filtrable, en haut. Leurs options sont recalculées en fonction des autres filtres actifs : impossible de choisir une combinaison qui ne donnerait aucune ligne.

5.4 Recherche libre

Le champ « Recherche libre » cherche dans tous les champs de l'onglet courant, codes et libellés : ZGMAG3, HUBT, tampon…

5.5 Tri et pagination

↕ à côté d'un intitulé : tri croissant / décroissant. Les tableaux affichent 200 lignes à la fois ; le bouton « Afficher 200 lignes de plus » en charge davantage.

5.6 Exporter et réinitialiser

  • Exporter CSV : exporte les lignes filtrées de l'onglet courant (compatible Excel : point-virgule + UTF-8 BOM).
  • Réinitialiser les filtres : efface filtres et recherche, garde les fichiers chargés.
  • Vider les fichiers : retour à l'état initial, tout est effacé de la mémoire.
  • Aide ❓ : la présente page.

6. Comment les recoupements sont calculés (règles de jointure)

  • F1 → Flux : clé = Dépôt + ZI + Groupe ZG départ. La ZE n'est pas utilisée volontairement : certains groupes sont déclarés sur une ZE dans F1 (ex. GZGHUB sur ZEHUB) mais utilisés sur d'autres dans F2 (ZEHUBE, ZEHU24).
  • F3 → Flux : clé = Dépôt + ZG. Une ZG peut exister dans plusieurs ZI/ZE (ex. ZGEINF dans ZIHUB et ZITOT) : toutes ses affectations sont montrées.
  • F4 → Flux : clé prioritaire = Dépôt + ZI + ZE + Groupe départ + Groupe arrivée ; à défaut, repli = Dépôt + Groupe départ + Groupe arrivée. Le chemin s'affiche « Séquence · EMPL1/EMPL2/EMPL3 · Libellé ».
  • Nettoyage automatique : lignes d'en-tête répétées en milieu de fichier ignorées ; lignes strictement dupliquées retirées une fois (compteur visible dans les KPI).

7. Onglet « Écarts » : ce qui est contrôlé

Chaque carte regroupe un type d'anomalie ; les pastilles indiquent le code concerné et le nombre de lignes. Cliquer une pastille bascule sur l'onglet concerné, filtré sur ce code.

  • Flux F2 sans tampon défini (F4) : aucun chemin tampon pour ce couple départ→arrivée.
  • Tampon F4 sans flux correspondant (F2) : ligne tampon orpheline.
  • Groupe de départ présent dans F2, absent de F1 : aucune ZG de départ référencée.
  • ZG d'arrivée sans affectation ZE dans F3 : ZG inconnue du référentiel ZIZEZG.
  • ZE du flux différente des ZE du référentiel : souvent volontaire (cf. §6), à valider par vous.
  • ZG de départ F1 absent du référentiel F3.
  • ZG du référentiel jamais utilisée : n'apparaît dans aucun groupe, ni départ ni arrivée.
  • Libellés ZG incohérents : plusieurs libellés différents pour un même code Dépôt+ZG dans F2.
  • Codes « groupe arrivée » atypiques : ne commençant pas par GZG (ZGPRO, PROD, GZES, GZOU). Ils existent tels quels dans F2 et F4 : les jointures fonctionnent, mais la carte vous rappelle de les normaliser si besoin.

9. FAQ / dépannage

  • « Fichier non reconnu » : la reconnaissance se fait par le contenu, pas par le nom. Vérifiez que le classeur contient bien les colonnes attendues (F4 doit avoir « EMPL 1 », F3 doit avoir « ZG », etc.).
  • Page vide ou « Librairie SheetJS non chargée » : connexion Internet requise au premier affichage. Pour un fonctionnement 100 % hors-ligne : téléchargez xlsx.full.min.js dans un dossier vendor/ à côté de index.html, puis remplacez l'adresse de la librairie dans la première balise <script> du fichier par vendor/xlsx.full.min.js.
  • Mes données partent-elles sur GitHub ? Non. Seuls index.html et aide.html sont en ligne ; vos classeurs sont lus localement par votre navigateur.
  • Tout a disparu quand j'ai fermé l'onglet : normal, rien n'est stocké. Rechargez les 4 fichiers.
  • Le CSV s'ouvre mal dans Excel : il est en UTF-8 avec BOM et séparateur point-virgule ; ouvrez-le via Données → From Text/CSV si le double-clic ne suffit pas.
  • Tableau trop long / lent : l'affichage est limité à 200 lignes ; filtrez ou cherchez d'abord, puis utilisez « Afficher plus ».

10. Exemple guidé : suivre « ZGMAG3 »

  1. Dans « Recherche libre », tapez ZGMAG3 : l'onglet Flux montre les flux où cette ZG intervient.
  2. Cliquez la pastille ZGMAG3 de la colonne « ZG arrivée » : le filtre devient persistant (pastille colorée).
  3. Lisez la ligne : groupe de départ (ex. GZGREC), ZG du groupe de départ (F1), ZE du référentiel (F3), chemin tampon (ex. « S1 · DZEC/T · Départ ZEC Tampon »).
  4. Cliquez l'intitulé 🔗 « Tampon · F4 » pour voir tous les tampons des flux filtrés, avec leurs occurrences.
  5. Terminez par « Exporter CSV » pour conserver le résultat filtré.
